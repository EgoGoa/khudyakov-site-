# Резервные копии

Перед каждым изменением кода сюда сохраняется копия затронутых файлов —
в подпапке с датой и временем, с тем же путём, что и в проекте.

Пример: _backups/2026-07-31_1530/src/components/home/Hero.tsx

Чтобы откатить изменение — просто скопируйте нужный файл из папки с нужной
датой обратно на его место в src/, заменив текущую версию.

Эта папка не участвует в сборке и деплое сайта.
