# Блог в подвале: как обновлять

Витрина в подвале сайта читает **один файл** — `content/blog/posts.json`.
Агент (или человек) раз в неделю перезаписывает его, делает коммит — сайт пересобирается.
Код трогать не нужно.

## Формат

- `updated` — дата обновления, `YYYY-MM-DD`.
- `posts` — массив материалов. Порядок не важен: сайт сортирует по `date` (новые первыми).

Поля материала:

| поле | обяз. | описание |
|---|---|---|
| `id` | да | уникальный, латиницей: `case-2026-10-fest` |
| `rubric` | да | `cases` · `trends` · `tools` · `team` |
| `title` | да | заголовок, до ~90 знаков |
| `excerpt` | да | 1–2 предложения, до ~160 знаков |
| `date` | да | `YYYY-MM-DD` |
| `readMin` | нет | минут чтения |
| `source` | для trends | название источника: `Sostav`, `vc.ru` |
| `url` | нет | ссылка на полный материал (пост в Telegram, страница). Без неё карточка не кликабельна |
| `metrics` | нет | только для `cases`: до 3 пунктов `{label, value, percent 0–100}` |

## Правила

- Только проверяемые факты. Не выдумывать цифры, клиентов, цитаты.
- `cases` — только работы из портфолио (`src/lib/data.ts`): название, хронометраж, год, формат — как в данных. Метрики (`metrics`) — только если их прислал Егор. `url` — `https://youtu.be/<youtubeId>`.
- `trends` — новости индустрии (Россия и мир): видеопродакшн, реклама, SMM, AI-инструменты. Обязательны `url` и `source`. Писать только то, что подтверждает сам источник; статью своими словами, без копирования. Если подтвердить нельзя, не публиковать.
- `tools` — обзор инструмента без выдуманных цифр. Можно без `url`.
- `team` — **только Егор**, агент эту рубрику не трогает.
- Показываются до 3 материалов выбранной рубрики, самые свежие. Пустая рубрика скрывается.
- В каждой рубрике хранить не более 12 материалов, старые удалять.

## Регулярное обновление (пн, ср, пт)

1. Добавить 1–2 новых материала в `trends`, `tools` или `cases`. Рубрики чередовать, не дублировать прежние темы и ссылки.
2. Поставить сегодняшнюю дату в `date` и `updated`.
3. Проверить: `npx tsc --noEmit`.
4. Ветка `claude/blog-update-YYYY-MM-DD` от `main`, коммит, push, pull request. В `main` напрямую не пушить: Егор проверяет и вливает сам.
